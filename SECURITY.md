# Security Policy

## Supported versions

Security fixes are provided for the latest published version of `image_cropper_gdx_plus`. Older versions may be asked to upgrade before a fix is evaluated.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository when available, or contact the maintainer through [gurwinderdevx.com](https://gurwinderdevx.com).

Include:

- affected package and version;
- affected platform and operating-system version;
- impact and realistic attack scenario;
- reproduction steps or a minimal proof of concept;
- any known mitigations.

You should receive an acknowledgement within seven days. Timelines for validation and remediation depend on severity, affected upstream native libraries, and release coordination. Please allow a reasonable remediation window before public disclosure.

For vulnerabilities in uCrop, TOCropViewController, or Cropper.js, also follow the security process of the affected upstream project.
