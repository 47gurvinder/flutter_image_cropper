# image_cropper_gdx_plus_for_web

Web implementation for the [`image_cropper_gdx_plus`](https://pub.dev/packages/image_cropper_gdx_plus) federated plugin.

Applications should depend on `image_cropper_gdx_plus` rather than this implementation package directly. The main package selects this implementation automatically on Web.

This package uses [Cropper.js](https://github.com/fengyuanchen/cropperjs). See the [main package documentation](https://github.com/47gurvinder/flutter_image_cropper/tree/master/image_cropper) for installation, configuration, usage, credits, and support.
